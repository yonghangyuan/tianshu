## 四、P1 — 工具生态（对标 OpenClaw Skills）

### P1-004 — MCP 协议支持
- **状态**: ⬜ 待办
- **创建**: 2026-07-28
- **描述**: 实现 Model Context Protocol client，对接 VS Code / 数据库 / 外部 API 等 MCP server。这是 OpenClaw 28K+ Skills 的核心基础设施
- **预计**: 3-5 天
- **OpenClaw 对标**: SkillHub 社区生态

### P1-005 — Playwright 浏览器引擎
- **状态**: ⬜ 待办
- **创建**: 2026-07-28
- **描述**: 当前 browser Skill 是纯 HTTP（无 JS）。加 Playwright 做真正的浏览器渲染：截图、点击、填表、翻页。截图 base64 发给多模态模型
- **预计**: 2-3 天
- **OpenClaw 对标**: Chrome CDP 全自动

### P1-006 — 文件上下文引用（@file）
- **状态**: ⬜ 待办
- **创建**: 2026-07-28
- **描述**: 输入 `@file.py` 自动读取文件内容注入上下文。支持 `@file.py:42` 指定行号。对标 Claude Code 的文件感知
- **预计**: 1 天

### P1-007 — Diff 预览 + Inline Edit
- **状态**: ⬜ 待办
- **创建**: 2026-07-28
- **描述**: 文件修改前展示 diff（+/- 行），用户确认后应用。对标 Claude Code 的编辑预览
- **预计**: 2 天
